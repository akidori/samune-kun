## 0. 一言サマリ

**「書道なのに、驚くほど明るくてポンコツで、でも"教える"と別人になる先生」**
YouTubeでは「頭良さそう・テキパキ」と見られている石野さんの"素"と"教える顔"のギャップを、1日密着で見せる。

## 1. 人物・事業メモ(ヒアリングより)

- 石野かほさん:教育書道家。夫とは夫婦であり事業パートナー(夫は戦略・裏方、書道は不可)。子ども3人、埼玉在住(※公開可否は未決)
- 事業:「大人のための書道学校」(店舗なし・完全オンライン・大人専用)。会員は約350名(海外在住の日本人)。FANTSのアプリで運営
- YouTube:書道ジャンルで登録者5〜6万人。1本で約60万再生のヒットあり
- 強み(本人たちが挙げた3点)
  1. 大人専用
  2. オンライン(教室・校舎なし)
  3. **プロも学ぶ**(書道教室の先生・師範など100名超が生徒)
- 提供価値:**暗黙知の言語化**。「見て学べ」で済まされてきたことを理論で説明する
- 肩書き:「書道家」ではなく「教育書道家」にこだわり(パフォーマンス系・作品系の書道家と区別したい)
- 現在は作品依頼・ロゴ制作などの書道家仕事は受けていない。筆を持つのはほぼお手本を書くときだけ
- 生徒には、書道以外の先生(ヨガ・ピラティス・フラダンス等)も「教え方」を学びに来ている

### 原体験(軸にできるストーリー)

石川県の書道教室の祖父 → 小学生で賞を総なめ → 両親の離婚・中学は書道から離れる → 高校で荒れて退学寸前、祖父に救われる → 老人ホームのボランティアで「書の力」を知る → 大東文化大学書道学科で落ちこぼれ(教わっても分からない) → 22歳で札幌に教室 → 独学で体系化し、分かりやすく教える今へ

→ 「自分が分からなかった側だから、分からない人に分かりやすく伝えたい」が全部の根っこ。

## 2. 動画の軸(決定したい方針)

| 項目 | 方針案 | 根拠 |
|---|---|---|
| 主題 | **「教える石野かほ」** | 本人・夫・FANTS側とも「教えている姿が一番の魅力」で一致 |
| 見せ方 | 業界批判ではなく、**教える姿と日常で思想を伝える** | 「思いは言うが攻撃はしない」。VS構造は避ける |
| トーン | 明るい・楽しい・あたたかい | 「書道=堅い・地味」の印象を覆したい |

| 主な視聴者 | 既存ファン(公開24時間以内の視聴者) | コラボ機能で相互流入も狙う |

## 4. 使える言葉・エピソード(テロップ/ナレーション素材)

- 「書道は習字と違う。習字は字を整える、書道は芸術」
- 「先生のお手本は100年、古典は2000年の歴史。だから先生のコピーになるなと言う」
- 「勉強していない字は100均の字に見える」
- 「センスの人からセンスを教わっても分からない」
- 「見て学べ、が一番つらかった。だから言語化した」
- 「書道はツールにすぎない。みんなが書道で幸せになればいい」
- 長女(小3・機械体操、週5・5時間、オリンピック志望)の名言「自信持つと楽しいよ」
- 「作品は死ぬとき全部燃やしてほしい」→その真意は"今はまだ恥ずかしいくらい学びの途中"
